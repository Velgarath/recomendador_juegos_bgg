# Board Game Recommender

Personal machine-learning project using BoardGameGeek data.

The goal of this project is to learn and experiment with different
machine-learning techniques while building a recommender system for
board games based on my own ratings and preferences.

## Project status

This is a personal learning project and is still evolving.

The main objective is not only to obtain the best possible prediction
score, but also to understand how different algorithms behave with the
same data.

The code is experimental and may change frequently as I learn.

## Current work

The project currently explores:

- Linear Regression
- Ridge, Lasso and Elastic Net
- Decision Trees
- Random Forest and Extra Trees
- Gradient Boosting
- XGBoost
- LightGBM
- CatBoost
- Support Vector Regression
- Kernel Ridge
- K-Nearest Neighbors

I am also comparing how different feature sets affect each model.

## Next steps

Planned areas of exploration include:

- Neural networks
- Factorization Machines
- Automatic feature selection
- Collaborative filtering
- Matrix factorization
- Hybrid recommender systems

## Data

The project uses public BoardGameGeek data together with my own game
ratings.
